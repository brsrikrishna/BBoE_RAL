# BBoE project page

https://brsrikrishna.github.io/BBoE_RAL/

Static project page for **BBoE: Leveraging Bundle of Edges for Kinodynamic Bidirectional Motion Planning** (IEEE Robotics and Automation Letters, 2026).

- `index.html`, `style.css`: the page (no build step, no external dependencies).
- `assets/`: figures, result plots, planning animations (MP4), and the supplementary video.

Published with GitHub Pages from the `main` branch. Code: https://github.com/brsrikrishna/bidirectional_bundle_of_edges_BBoE
